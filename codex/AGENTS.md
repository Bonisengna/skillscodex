# Acordo de orquestração de engenharia

Este é um modelo para mesclar às instruções do projeto ou do usuário durante a instalação. Não substituir instruções existentes nem instalar automaticamente.

Para pedidos de planejamento, implementação, revisão ou evolução de software, usar `$stack-engineering-orchestrator` como ponto de entrada. Consultas pontuais sem trabalho de projeto não precisam convocar a equipe.

- Ler a skill completa pelo catálogo disponível ou por `skills/stack-engineering-orchestrator/SKILL.md` quando este repositório estiver acessível. Se não estiver instalada/disponível, informar o que falta, sem fingir execução.
- Identificar projeto novo ou existente; perguntar apenas o que não estiver respondido. Discutir alternativas e obter aprovação antes de decisões estruturais.
- Usar subagentes para partes independentes ou revisão independente quando agregarem valor. Selecionar modelos disponíveis conforme risco e critérios da skill. Não iniciar todos os papéis por padrão.
- Manter um só dono da distribuição. Começar com até dois subagentes simultâneos; respeitar o teto configurado e permissões do ambiente.
- Não ampliar escopo, orçamento, fornecedor, acesso, instalação ou publicação sem autorização. Não reduzir verificações críticas por falta de modelo/ferramenta.
- Se só houver execução sequencial ou modelo herdado, declarar a limitação. Registrar o que foi realmente testado e não liberar release com lacunas essenciais.

Configurações locais não modificam automaticamente ChatGPT Work. A skill e este acordo não substituem controles de acesso, revisão humana, testes de CI ou proteção de branches.
