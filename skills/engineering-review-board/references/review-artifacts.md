# Quatro documentos oficiais

## 1. ENGINEERING_REVIEW_REPORT.md

Inclua escopo, versão, ambiente, especialistas, evidências, áreas não avaliadas, achados consolidados e veredito.

Cada achado contém: ID, título, área, alvo, evidência, reprodução, impacto, severidade e fundamento, confiança, recomendação, alternativa, testes e critério de resolução.

## 2. REMEDIATION_PLAN.md

Inclua ordem de correção, dependências, responsável, abordagem aprovada, testes, riscos da mudança e condição de rollback. Não aplique antes da aprovação.

## 3. ACCEPTED_RISKS.md

Para cada risco: achado, decisão, justificativa, impacto conhecido, controle compensatório, responsável, prazo e data de reavaliação. Críticos e altos não podem ser aceitos como forma de liberar o gate padrão.

## 4. REVERIFICATION_REPORT.md

Inclua versão corrigida, achado original, teste específico, regressões executadas, evidência, status e veredito atualizado.

Preserve IDs dos achados entre documentos para rastreabilidade.
