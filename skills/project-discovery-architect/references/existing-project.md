# Rota para projeto existente

Solicite somente os materiais relevantes: repositório ou arquivos, documentação, estágio, funcionalidades, stack, decisões anteriores, problemas conhecidos, restrições e objetivo da revisão.

Antes de reorganizar:

1. inventarie componentes e responsabilidades;
2. identifique fonte de verdade e fluxos críticos;
3. compare documentação com implementação;
4. registre falhas, dívida, riscos e lacunas;
5. separe o que deve ser preservado, reparado, substituído ou investigado;
6. proponha uma sequência segura e incremental.

Não interprete código diferente de sua preferência como defeito. Fundamente mudanças em requisito, risco, custo ou manutenção demonstrável.
